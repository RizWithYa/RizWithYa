### Selected Work & Projects

#### 1. Daypath (Mobile App)
Daypath is a modern productivity application that combines a robust **Task Management system** with **Islamic Prayer Times**, wrapped in a striking **Neubrutalism UI** design system.
*   **Technologies:** Flutter, Dart
*   **Key Highlights:** Sleek custom gesture-driven interfaces, local scheduling of prayer alerts, lightweight state management, offline availability.
*   **Repository:** [github.com/RizWithYa/Daypath](https://github.com/RizWithYa/Daypath)

#### 2. Nutrify (Mobile App)
A personalized mobile application to track daily calorie and macronutrient intake, tailored to individual body fitness and dietary goals.
*   **Technologies:** Flutter, Dart, PostgreSQL
*   **Key Highlights:** Integrated calorie budget calculators, body goal onboarding wizard, analytics dashboards, offline-first local cache synchronization.
*   **Links:** [Google Play Store](https://play.google.com/store/apps/details?id=com.nutrifier.app) | [Live Landing Page](https://nutrify-landing.vercel.app) | [Repository](https://github.com/ErickHaidar/Nutrify)

#### 3. MindMap MVP (Web Canvas)
A frictionless, lightweight anonymous mind-mapping web canvas designed for zero-cost scaling on free-tier infrastructure. It allows users to design mindmaps and share them instantly via tokenized access parameters without registering.
*   **Technologies:** Next.js 14 (App Router), Supabase (PostgreSQL JSONB), React Flow (`@xyflow/react`), Tailwind CSS, Vercel
*   **Key Highlights:** 3-Level Token Access System (`owner`, `editor`, `viewer`) managed strictly via server-side Row Level Security (RLS) policies; debounced auto-sync utilizing a Last Write Wins mechanism; multi-format canvas exporting (PNG, PDF, and raw JSON configurations).
*   **Infrastructure Cost:** $0.00 / month (100% within free-tier limits)

#### 4. Medical Record System with ASR (Web & AI)
An intelligent voice-enabled clinical system integrating traditional information system development with Automatic Speech Recognition (ASR) to enhance patient record-entry efficiency.
*   **Technologies:** Next.js, Python, ASR Models, PostgreSQL
*   **Key Highlights (WIP):** Integrating AI transcription models to capture doctors' verbal assessments, mapping conversational speech straight to structured medical database fields, eliminating manual typing overhead.
